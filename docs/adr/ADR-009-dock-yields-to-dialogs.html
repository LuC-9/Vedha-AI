Architecture decisions · ADR-009

Unpinned copilot yields to application dialogs

ACCEPTED Extension 2026-10-10
Plain version. When an application window opens, the floating Vedha card gets out of the way. It shrinks to the small pill and sits underneath the window so Next, Review, and Discard stay clickable. If you pinned the card on purpose, it stays large and on top. On Google, a new tab, or any page that is not a job, the toolbar popup still opens the full career dashboard instead of spinning on “Detecting target job…”.

Context

LinkedIn, Greenhouse, Lever, and Workday mount application UI in dialogs whose host z-index is around 1000. The copilot root used 2147483647 at all times, including while those dialogs were open. A later pin feature made “always above modals” the default path inside manageModalStacking. That kept the dock on top of Discard confirmations and the Easy Apply footer.

Separately, popup.js blocked boot on GET /api/auth/me and on chrome.tabs.sendMessage. The toolbar action had no popup, so the icon depended on the side-panel click listener.

Decision

Stacking

  • Dialogs are sorted by a walk of document.body. Harness DOM has no compareDocumentPosition.
  • Base z-index is 2147483100. Each later dialog adds 100. Backdrops use modalZ - 1.
  • LinkedIn messaging trays drop to 1000 while a dialog is open.
  • Unpinned dock: one-shot capture of expanded state, collapse to #vedha-copilot-pill, z-index 2147482000. The 350ms pulse must not recapture after collapse.
  • When no dialog remains, z-index returns to 2147483647 and a previously expanded card is shown again. Drag coordinates in vedha_dock_x / vedha_dock_y are not rewritten.
  • Pinned dock stays expanded at 2147483647. Pin is the explicit “cover the page” override.

Popup

  • action.default_popup is popup.html. Side panel default_path stays popup.html.
  • Boot writes Universal Careers Mode before awaiting auth or the active tab.
  • fetch and tabs.sendMessage race a 2500ms timer. 401 and 403 clear the session. Other failures keep cachedUser, candidateProfile, and cachedMasterResume.
  • Restricted URLs and non-job hosts never wait on the content script.
  • Missing notice period, salary, and visa sponsorship render as “Not Specified”.

Alternatives

OptionWhy it lost
Keep the dock at 2147483647 and only move it with dragThe default corner still covers Next and Submit. Users should not have to drag before they can close a dialog.
Collapse even when pinnedThe pin control promises the card stays over modals. Existing pin tests require the card to stay visible.
Leave the icon on the side panel onlyIssue #5 asks for the toolbar popup on every site, including new tabs.

Consequences

Clicking the toolbar icon opens the popup and does not fire chrome.action.onClicked, so the icon no longer opens the side panel by itself. The side panel remains available from Chrome’s side-panel UI because side_panel.default_path is unchanged.
